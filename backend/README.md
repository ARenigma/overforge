# Backend

Node.js/Express server for managing rooms, users, real-time collaboration, and integration with code execution and AI modules.

## Structure

- `src/index.js` — Main entry point
- `src/routes/` — API route handlers
- `src/controllers/` — Business logic
- `src/models/` — DB models/schemas
- `src/config/` — Config files (DB, etc.)
- `src/middleware/` — Middleware (auth, error handling)
- `src/sockets/` — Socket.io logic
